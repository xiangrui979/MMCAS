# 论文结构与章节规范（MMCAS 论文手）

## 开始写作前

1. 确认比赛类型：国赛读 `references/cumcm-guide.md`，美赛读 `references/mcm-icm-guide.md`。
2. 确认写作阶段：规划（结构+各节要点）→ 写作（具体章节）→ 润色 → 检查。
3. 素材来源纪律：模型与符号以建模手文件为准（`workspace/analysis/`），数字与图表以编程手任务卡为准。没有上游出处的数字，用占位符标记，禁止自行编造——交稿前所有占位符必须清零。

## 国赛结构速查

| 章节 | 篇幅 | 要点 |
|---|---|---|
| 摘要 | 1 页 | 每问必有量化结果；六要素：问题、方法、结果、结论、亮点、关键词 |
| 问题重述 | 0.5-1 页 | 用自己的语言拆题，不复制原题 |
| 问题分析 | 1-2 页 | 为什么选这个模型（不是"将用什么方法"）；附建模流程图 |
| 模型假设与符号 | 1 页 | 假设逐条配解释；符号与建模手 notation.md 一致 |
| 数据处理 | 2-4 页 | 为什么这么处理（内容少可嵌入第一问） |
| 问题一/二/三建模与求解 | 各 4-7 页 | 目标→理由→公式→求解→结果→分析→检验 |
| 模型评价与改进 | 1-2 页 | 评价模型本身（优缺点+检验结论），不是评价算法 |
| 参考文献 | ≥6 条 | 期刊论文+英文文献 |
| 附录 | 按需 | 完整代码+支撑材料 |

正文 20-28 页（不含附录）。灵敏度/误差分析通常嵌在各子问题求解末尾；内容充实（2 页+）才独立成章。美赛结构见 mcm-icm-guide.md（Summary Sheet 一页 hook 句+量化结果全覆盖）。

## 各节"四步"写作法

每节按「目的→结构→写什么→红线」执行：
- **目的**：这一节要论证什么。
- **结构**：按模板骨架组织。
- **写什么**：从上游素材选取内容。
- **红线**：不能写什么（如问题重述不能复制原题、模型评价不写空话）。

## 模型检验与灵敏度（高奖分水岭）

- 建模手任务卡里的检验需求必须逐条落实到论文（灵敏度分析/稳健性/基线对比）。
- 检验结果由编程手提供，论文手负责组织表达；缺失检验的模型 = 不完整的模型。
- 检验写作规则见 `references/model-validation.md`。

## 题型策略

不同题型（预测/优化/评价/机理）评审侧重不同，写作策略见 `references/problem-type-strategies.md`。美赛 Memo/Letter 见 `references/memo-writing.md`。
