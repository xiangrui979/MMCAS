# 交稿前四轮自审（MMCAS 论文手）

全文完成后**必须**执行，逐轮通过才能进入下一轮。四轮框架细节见 `references/self-review-framework.md`。

## 第一轮：论证逻辑（最重要，区分三等奖与一等奖）

- 每个主张是否有证据（推导/数据/图/表/文献）支撑？悬空主张、跳跃逻辑、循环论证必须修复。
- 每个数字能否回溯到编程手任务卡记录？数字链断裂的一律修复或删除。
- 结论与证据强度匹配吗？（弱证据下强结论 = 危险）

## 第二轮：章节结构

- 摘要六要素齐全、每问有量化结果。
- 建模求解各节要素完整（目标→理由→公式→求解→结果→分析→检验）。
- 模型假设逐条配解释；符号与建模手一致。

## 第三轮：表述质量

- 按 `mm-paper-style` 去 AI 味清单逐条扫描。
- 数据准确性：正文数字与图表数字、摘要数字三方一致。
- 中英术语、标点、单位规范。

## 第四轮：格式规范

- 图表编号连续且被正文引用；参考文献格式统一且引用真实。
- 页码、模板规范、匿名要求（美赛控制号/国赛承诺书与编号页）。
- LaTeX 预检脚本跑通（见 mm-latex-cumcm：引用检查、关键词检查、PDF 页数/尺寸检查）。

## 独立审稿视角（有 subagent 时）

派独立 subagent 只拿冻结的论文稿 + 赛题 + 规则做盲审（不读写作过程），按 `references/report-schema.md` 出报告：
- 需求覆盖（每问是否都答了、有没有改目标）
- 主张-证据审计（摘要与结论的每个数字追溯到推导/数据/代码）
- 数学审计（定义、单位、边界条件、目标函数语义、极限情形）
- 评分区间与修复建议（按后果排序：P0 改变主答案 / P1 实质提升 / P2 润色）

盲审报告交建模手（Master）做最终复核。无 subagent 时降级为自审并标注"同上下文审阅，置信度降低"。

## 结论

四轮全过 → 在任务卡标注"通过四轮自审"并请人类审批提交。未过 → 修复后重新自审，修复记录留痕。
