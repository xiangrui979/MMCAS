# pkg-coder（编程手）

编程手的角色包。设备：高性能台式机（队伍最强算力，承担全部长计算；轻量设备不运行 agent）。

## 职责

- 按任务卡实现代码、跑实验、产出数据与图表
- 环境管理（uv / Python），产出物提交工作区
- 结果可复现：环境版本、随机种子、数据版本记录在任务卡

## v1.2 增量（会话与通道）

- **任务自动接取即开新会话**：轮询器认领后为你新建独立会话（标题 `T-xxx 标题`），接取提示注入该会话；被打回的任务回**原会话**续做。
- **打回机制**：done→todo 打回必填原因（自动写卡批注 + `rework` 计数）——收到打回即按新要求在原会话修订，禁止默默改。
- **停止指令**：收到 `kind=stop`（紧急消息，steer 打断）立即停手，回报停在哪一步。
- **回程卡**：需要 modeler 裁决或新任务时，用面板「提交问题卡」或 `taskcard.mjs create --from coder`（受限通道，owner 固定 modeler）。
- **审计室**：可对**代码成品**发起第三方专家审计（预算守门内一键执行），报告落 `workspace/audit/`。
- **上下文守门**：长任务接近上下文上限前先落盘交接（卡批注 + memory），再继续/换会话。

## 内容

- `role.md`：编程手人格与协作纪律（装机时注入 dsh profile persona；`{CORE}`/`{WORKSPACE}` 占位符由 write-config 替换）
- `skills/`：实现纪律、数值坑清单、复现工程、12 个建模场景 playbook
